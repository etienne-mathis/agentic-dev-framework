== Zweck dieses Dokuments

Die GitHub-Labels sind der Maschinen-Zustand (was ist offen/in Arbeit/fertig). Dieses
Dokument ist der *menschenlesbare Prosa-Zustand*: Es fasst in wenigen Absätzen zusammen,
was gebaut ist, woran gerade gearbeitet wird, welche Entscheidungen offen sind und welche
bekannten Schulden existieren. Es ermöglicht einen Kaltstart, ohne den ganzen Issue-Verlauf
zu lesen. Der RETRO-Agent schreibt es nach jedem Retro-Lauf fort.

Agnostische Regel: kurz halten (Zielgröße ~1 Bildschirmseite). Abgeschlossenes wandert in
knappe Historie oder wird gelöscht — dieses Dokument beschreibt die *Gegenwart*, kein Changelog.
